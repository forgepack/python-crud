## 🔐 Como Autenticar no Swagger

1. Acesse http://127.0.0.1:9001/docs
2. Clique no botão "🔒 Authorize" (topo direito)
3. Selecione "BearerAuth"
4. Cole seu token JWT:
   ```
   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```
5. Clique "Authorize"
6. Agora todos os endpoints protegidos funcionarão!


## 📋 Endpoints Documentados

🟢 PÚBLICOS (sem autenticação):
   ├─ GET /health ............................ Verificar saúde
   ├─ GET / ................................ Home
   ├─ POST /user/login ..................... Fazer login (obter token)
   └─ POST /admin/init/create-first-user .. Criar primeiro usuário

🔵 AUTENTICADOS (com Bearer token):
   ├─ Users:
   │  ├─ POST /user/ ....................... Criar usuário
   │  ├─ GET /user/ ........................ Listar usuários
   │  ├─ GET /user/{id} ................... Obter usuário
   │  ├─ PUT /user/ ........................ Atualizar usuário
   │  └─ DELETE /user/{id} ................ Deletar usuário
   ├─ Roles:
   │  ├─ POST /role/ ....................... Criar role
   │  ├─ GET /role/ ........................ Listar roles
   │  ├─ PUT /role/ ........................ Atualizar role
   │  └─ DELETE /role/{id} ................ Deletar role
   └─ Permissions:
      ├─ GET /permissions/ ................ Listar permissões
      ├─ DELETE /permissions/{id} ........ Deletar permissão
      ├─ PATCH /permissions/{id}/soft-delete .. Soft delete
      └─ PATCH /permissions/{id}/restore ... Restaurar
