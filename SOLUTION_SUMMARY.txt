📋 PROBLEMA RELATADO:

"Não consigo acessar os endpoints"

╔════════════════════════════════════════════════════════════════════════════╗
║                          🔴 PROBLEMAS ENCONTRADOS                          ║
╚════════════════════════════════════════════════════════════════════════════╝

1. ❌ CORS Configurado Incorretamente
   └─ Apenas método POST era permitido
   └─ Métodos GET, PUT, PATCH, DELETE retornavam erro CORS

2. ❌ Ponto de Entrada Faltando
   └─ app/main.py não tinha "if __name__ == '__main__':"
   └─ Comando "python -m app.main" não funcionava

3. ❌ Autenticação JWT Obrigatória em Todos os Endpoints
   └─ Impossível criar primeiro usuário (bootstrap)
   └─ Ciclo infinito de dependências

4. ❌ Banco de Dados Não Acessível
   └─ DATABASE_URL mal formatado (.env)
   └─ Todos os endpoints retornavam erro 500

5. ❌ Documentação Incompleta
   └─ Não havia referência de endpoints
   └─ Usuários não sabiam como usar a API


╔════════════════════════════════════════════════════════════════════════════╗
║                           ✅ SOLUÇÕES APLICADAS                            ║
╚════════════════════════════════════════════════════════════════════════════╝

✓ FIXO #1: CORS Configuração
  ├─ Arquivo: app/main.py
  └─ Alteração: allow_methods = ["GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"]

✓ FIXO #2: Ponto de Entrada
  ├─ Arquivo: app/main.py
  ├─ Adicionado: if __name__ == "__main__":
  └─ Resultado: python -m app.main agora funciona perfeitamente

✓ FIXO #3: Bootstrap de Usuário
  ├─ Arquivo: app/routers/admin.py
  ├─ Novo Endpoint: POST /admin/init/create-first-user
  └─ Descrição: Cria primeiro usuário sem exigir autenticação

✓ FIXO #4: Configuração do Banco
  ├─ Arquivo: .env.example
  └─ Atualizado: DATABASE_URL=postgresql://user:password@host:port/dbname

✓ FIXO #5: Documentação
  ├─ ENDPOINTS.md .............. Referência completa de todos os endpoints
  ├─ QUICKSTART.md ............ Guia de início rápido (5 minutos)

2️⃣  CRIE O PRIMEIRO USUÁRIO (em outro terminal)
    ┌─────────────────────────────────────────────────────────────────────┐
    │ $ curl -X POST http://127.0.0.1:9001/admin/init/create-first-user \│
    │   -H "Content-Type: application/json" \                            │
    │   -d '{                                                             │
    │     "username": "admin",                                           │
    │     "email": "admin@example.com",                                  │
    │     "password": "Admin@123456",                                    │
    │     "full_name": "Administrator"                                   │
    │   }'                                                                │
    └─────────────────────────────────────────────────────────────────────┘

3️⃣  FAÇA LOGIN PARA OBTER TOKEN JWT
    ┌─────────────────────────────────────────────────────────────────────┐
    │ $ curl -X POST http://127.0.0.1:9001/user/login \                 │
    │   -H "Content-Type: application/json" \                            │
    │   -d '{                                                             │
    │     "username": "admin",                                           │
    │     "password": "Admin@123456"                                     │
    │   }'                                                                │
    │                                                                     │
    │ Resposta: { "access_token": "eyJhbGciOiJIUzI1NiIs..." }          │
    └─────────────────────────────────────────────────────────────────────┘

4️⃣  USE OS ENDPOINTS COM O TOKEN
    ┌─────────────────────────────────────────────────────────────────────┐
    │ $ TOKEN="seu_token_aqui"                                            │
    │                                                                     │
    │ $ curl -X GET http://127.0.0.1:9001/user/ \                       │
    │   -H "Authorization: Bearer $TOKEN"                                │
    └─────────────────────────────────────────────────────────────────────┘

5️⃣  ACESSE A DOCUMENTAÇÃO INTERATIVA
    ┌─────────────────────────────────────────────────────────────────────┐
    │ Abra no navegador: http://127.0.0.1:9001/docs                     │
    │ (Swagger UI interativo para testar todos os endpoints)             │
    └─────────────────────────────────────────────────────────────────────┘

╔════════════════════════════════════════════════════════════════════════════╗
║                          📋 ENDPOINTS PRINCIPAIS                           ║
╚════════════════════════════════════════════════════════════════════════════╝

🔓 PÚBLICOS (Sem Autenticação)
├─ GET  /health ................................. Verificar saúde
├─ GET  / ........................................ Home
├─ POST /user/login .............................. Obter token JWT
└─ POST /admin/init/create-first-user .......... Criar primeiro usuário

🔐 AUTENTICADOS (Requer Token JWT no Header)
├─ Usuários:
│  ├─ GET  /user/ ................................ Listar usuários
│  ├─ POST /user/ ................................ Criar usuário
│  ├─ GET  /user/{id} ............................ Obter usuário
│  ├─ PUT  /user/ ................................ Atualizar usuário
│  └─ DELETE /user/{id} .......................... Deletar usuário
├─ Roles:
│  ├─ GET  /role/ ................................ Listar roles
│  ├─ POST /role/ ................................ Criar role
│  ├─ GET  /role/{id} ............................ Obter role
│  ├─ PUT  /role/ ................................ Atualizar role
│  └─ DELETE /role/{id} .......................... Deletar role
└─ Permissões:
   ├─ GET  /permissions/ ......................... Listar permissões
   ├─ GET  /permissions/{id} ..................... Obter permissão
   ├─ PATCH /permissions/{id}/soft-delete ....... Soft delete
   └─ PATCH /permissions/{id}/restore ........... Restaurar
